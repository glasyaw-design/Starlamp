# 별빛 등불 마법상점 (1.0.0-RC2 · 2026-10-28)

중세 판타지 마법상점을 꾸려 가는 2D 도트 웹게임이에요. 순수 HTML·CSS·JS로 만들었어요.

## 들어 있는 것

| 경로 | 쓰임 |
|---|---|
| `index.html`, `js/`, `css/`, `fonts/` | 게임 |
| `api/account.js` | 계정 서버(Vercel 함수): 가입·로그인·복구 코드로 비밀번호 찾기·클라우드 저장 |
| `package.json`, `vercel.json` | Vercel 설정 |
| `로그인_설정_안내.md` | Upstash 연결, 관리자 키, 비밀번호 초기화 방법 |

## 배포 (Vercel)

1. 이 저장소를 Vercel에서 **Add New → Project**로 가져와요. 빌드 설정은 그대로 두면 돼요.
2. **Storage → Upstash for Redis**를 만들어 이 프로젝트에 연결해요.
3. (선택) 환경 변수 `STARLAMP_ADMIN_KEY`에 16자 이상의 비밀 글자를 넣어요.
4. 다시 배포한 뒤 `/api/account?debug=1`을 열어 `"ok":true`인지 확인해요.

로그인하지 않아도 게임은 브라우저에 저장돼요. 비밀 키는 이 저장소에 넣지 말고 Vercel 환경 변수로만 넣으세요.

## 라이선스 확인

도트 그래픽과 효과음은 코드가 직접 만들어요. 글꼴은 넥슨 메이플스토리 서체예요. 공개 저장소에 올리기 전에 서체 재배포 조건을 확인해 주세요.
